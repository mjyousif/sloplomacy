## 2024-05-19 - Mouse hover causing severe recalculations in large React components
**Learning:** In complex interactive maps (like `EuropeMap.tsx`), UI interactions like mouse hovers trigger local state changes (e.g., `setHoveredProv`), which cause full component re-renders. If derived data arrays or objects (like `unitsByProv`) are re-created inline without `useMemo`, they generate new object references. These new references instantly bust the memoization of downstream `useCallback` hooks and other `useMemo` blocks. In this codebase, this was causing expensive operations like `canUnitSupportInto` and full topological graph iterations to run up to 60 times a second on a simple mouse movement, leading to severe visual lag.
**Action:** Always wrap derived objects and arrays in `useMemo` in heavy React components, and wrap function dependencies in `useCallback`. Before adding state that updates continuously (like hover tracking or cursor coordinates), audit all inline object creations to ensure they don't trigger cascading recalculations.
